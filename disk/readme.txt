■ 動作環境
    Microsoft Windows95以降, Microsoft WindowsNT4.0 ServicePack3以降
    256色発色可能で640x480dots以上のディスプレイ環境が必要です。
    (ウインドウモードなら 65535色以上で800x600以上推奨)

    Microsoft DirectX 3以降がインストールされていると、
    フルスクリーンや DirectSound などで快適なプレイができます。



■ スタートメニューについて
    標準では Bio_100% というグループの中の SuperDepth というグルー
    プに各種ショートカットを作成します。このテキストでは、この標準
    でのグループを元に書かれています。



■ このゲームのマニュアルについて
    SuperDepth の遊び方などは、HTML形式で提供されています。
    ご覧になるには Internet Explorer や Netscape Navigater 等の
    ブラウザが必要です。

    このマニュアルをご覧になるには、[SuperDepth]のグループの中に
    [マニュアル]という項目がありますので、これを選択してください



■ オンラインアップデート機能について
    この SuperDepth では、インターネット経由によるソフトウェアの
    オンラインアップデート機能があります。この機能を実行することに
    よって、SuperDepthを簡単に最新版にすることができます。
    実行する前に、インターネットに接続しておいてください。



■ プロキシ経由でオンラインアップデートを利用するには？
    オンラインアップデート設定プログラムを用意しています。
    このプログラムを利用することによって、プロキシを設定することが
    できます。
    [SuperDepth]のグループにある[オンラインアップデート設定]を
    選んで下さい。そして画面に従って設定をしてください。



■ アンインストールについて
    アンインストールを行う場合は、コントロールパネル内の
    ｢アプリケーションの追加と削除｣を使用してください。
    また、一度オンラインアップデートによって更新されたファイルは
    アンインストール後にも残ってしまいますので、お手数ですが
    あとからそれらのファイルを削除してください。



■ このセットアッププログラムについて
    セットアップで組み込まれるバージョンは Build 115 です。
    99/02/14 00:10に提供されたものです。インストール時には最新版が
    提供されている可能性が高いので、インターネットが利用できる方は
    オンラインアップデートを実行してみましょう。
